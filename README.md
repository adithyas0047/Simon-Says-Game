# Simon Says Game 🎮

A fun web-based **Simon Says Game** built using HTML, CSS, and JavaScript. The game tests your memory by flashing a sequence of colored buttons which the user must repeat correctly to advance to higher levels.

## 🚀 Features

- Interactive UI with four colored buttons
- Sequence generation and user input validation
- Visual feedback with button flashes
- Level progression with score tracking
- High Score tracking (stored per session)
- Keyboard-based game start

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the color sequence displayed.
3. Repeat the sequence by clicking the correct colored buttons in order.
4. Each correct sequence takes you to the next level.
5. Game ends when you press a wrong button.
6. Try to beat your high score!
